Ultraviolet App is an all-in-one, production-ready deployment of [Ultraviolet](https://github.com/titaniumnetwork-dev/Ultraviolet) — a sophisticated web proxy that rewrites pages through a service worker to evade internet censorship. Drop it on any Node.js host, a Docker container, or a one-click platform and your users can browse the web freely within seconds.

## What's included

Ultraviolet App bundles everything you need to run a full proxy in production:

- **Ultraviolet core** — service-worker URL rewriter served at `/uv/`
- **EpoxyTransport** — encrypted HTTP transport served at `/epoxy/`
- **BareMux** — pluggable transport abstraction served at `/baremux/`
- **Wisp WebSocket tunnel** — low-latency WebSocket proxy at `/wisp/`
- **Express 5 server** — static asset serving with COOP/COEP security headers

## Quick look

```bash
git clone https://github.com/titaniumnetwork-dev/Ultraviolet-App.git
cd Ultraviolet-App
pnpm install
pnpm start
```

Open [http://localhost:8080](http://localhost:8080) and start browsing.

<Note>
  Firefox requires a valid SSL certificate to register service workers. Use a Chromium-based browser when testing on `localhost`.
</Note>
